## Reading

The index on `Event.date` only reduces database hits for `top_events` (9,357 vs 18,332), because it avoids a full sort. For `top_countries` it is actually more expensive (45,272 vs 22,767 hits): the analysis window (February to July) covers all events, so the index is not selective and a label scan is cheaper. The other three queries rely on the `TradingDay.date` index and do not depend on the one on `Event.date`; their identical measurements serve as a control.
