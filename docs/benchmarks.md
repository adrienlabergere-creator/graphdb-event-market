## Interpretation

The `Event.date` index saves 8,963 database hits for `top_events` in this window. The EXPLAIN and PROFILE plans above show an index seek with the index and a label scan without it.
For `top_countries`, the indexed plan uses 22,496 more database hits: the measured window covers nearly every event, so the index is not selective. The other three queries do not depend on `Event.date`; their nearly identical counts are a control. These small, warmed-run timings describe this dataset and machine, not a general speedup.
